# 🌍 What is Cursor?

Cursor is an AI-powered code editor built on top of Visual Studio Code. It combines the familiar VS Code experience with advanced AI capabilities, helping developers write, understand, edit, and debug code more efficiently.

Rather than acting as a simple autocomplete tool, Cursor is designed to function like an intelligent coding partner that understands your entire codebase.

---

# 🎯 The Problem It Solves

Modern software projects can contain thousands of files, making it difficult to understand unfamiliar codebases.

Cursor helps developers by:

- Explaining existing code
- Generating new code
- Refactoring functions
- Finding bugs
- Answering questions about the project
- Editing multiple files using natural language

This allows developers to spend less time searching and more time building.
