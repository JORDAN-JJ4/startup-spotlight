# 🚀 Startup Spotlight #001 — Supabase

## Overview

Supabase is an open-source Backend-as-a-Service (BaaS) platform. It helps developers build modern applications by providing authentication, PostgreSQL databases, storage, APIs, and real-time features without having to build everything from scratch.

---

## Founded

- **Year:** 2020
- **Founders:** Paul Copplestone, Ant Wilson, Steve Chávez
- **Headquarters:** Singapore

---

## Problem It Solves

Developers often spend weeks building backend infrastructure.

Supabase simplifies this by offering ready-to-use backend services so developers can focus on building their applications.

---

## Main Features

- PostgreSQL Database
- User Authentication
- File Storage
- Realtime Database
- Edge Functions
- Auto-generated REST APIs

---

## Why It's Popular

✅ Open Source

✅ PostgreSQL-based

✅ Excellent documentation

✅ Easy to learn

✅ Generous free tier

---

## Business Model

Supabase follows a **freemium** model.

- Free plan for individual developers
- Paid plans for teams and production applications
- Enterprise solutions for larger organizations
